# OHLI Social v3.6.21 — Rencana pengujian

## Sorotan
1. Buka profil pada iPhone Safari dan Android Chrome.
2. Pastikan setiap sampul Sorotan benar-benar 1:1 dan bulat; gambar/video tidak membuat ring melebar atau lonjong.
3. Uji nama Sorotan panjang, cover portrait, cover landscape, dan cover video.

## Riwayat aktivitas
1. Dari akun uji, buka profil, postingan teks, foto, video, dan Story yang dapat dilihat.
2. Buka Profil > Riwayat aktivitas.
3. Pastikan kartu dikelompokkan menurut tanggal, thumbnail sesuai jenis media, dan waktu tampil.
4. Tekan profil untuk membuka profil; tekan postingan untuk membuka postingan asli; tekan Story aktif/Story milik sendiri untuk membuka pemutar Story.
5. Uji akun kedua: konten yang aksesnya dicabut atau sudah dihapus tidak boleh dapat dibuka dari History.
6. Hapus riwayat dan pastikan catatan akun lain tidak terpengaruh.

## Notifikasi tanpa WhatsApp API
1. Jalankan APK server dan izinkan notifikasi Android ketika sistem memintanya.
2. Uji server mulai, server berhenti, error server, keberhasilan verifikasi, serta permintaan OTP.
3. Pastikan notifikasi Android muncul dan menaut ke aplikasi pengelola.
4. Buka Pusat Notifikasi; pastikan daftar tersimpan, tanggal tampil, badge belum dibaca berkurang setelah dibuka, dan OTP kedaluwarsa tidak ditampilkan lagi.
5. Pastikan OTP tetap hanya tampil pada notifikasi privat khusus dan tidak muncul di kanal notifikasi umum.

## Build
- Jalankan workflow `.github/workflows/build-apk.yml` dari root repository.
- Pastikan `:app:compileDebugJavaWithJavac` dan `:app:assembleDebug` berhasil.
- Tes runtime tetap dibutuhkan; pemeriksaan statis tidak menggantikan tes dua akun dan perangkat nyata.

## Batasan
- Tanpa WhatsApp Business/API, aplikasi tidak mengirim pesan WhatsApp secara otomatis. Notifikasi otomatis dikirim ke Android dan disimpan di Pusat Notifikasi APK. Pengiriman melalui WhatsApp harus dilakukan manual dari perangkat admin.
