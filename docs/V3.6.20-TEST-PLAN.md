# OHLI Social v3.6.20 — Rencana pengujian kamera LIVE

## iPhone / Safari
1. Masuk ke OHLI dan buka Studio LIVE melalui HTTPS.
2. Izinkan kamera dan mikrofon. Pastikan preview Host menampilkan gambar, bukan avatar inisial.
3. Mulai LIVE dan tonton dari perangkat kedua. Pastikan video Host terlihat.
4. Tekan tombol ganti kamera. Pastikan status berubah ke kamera belakang dan preview Host ikut berubah.
5. Pastikan perangkat kedua juga menerima gambar dari kamera belakang, bukan layar hitam atau frame lama.
6. Tekan ganti kamera lagi dan pastikan kembali ke kamera depan pada Host dan penonton.
7. Matikan kamera lalu hidupkan lagi; avatar hanya tampil saat kamera mati.
8. Akhiri LIVE dan pastikan indikator kamera/mikrofon berhenti.

## Android Chrome
Ulangi langkah 1–8.

## Pemeriksaan regresi
- Undang peserta kedua; pastikan Host dan peserta saling melihat.
- Periksa komentar, mikrofon mute/unmute, dan keluar panggung.
- Pastikan chat, Story, Sorotan, upload dan login tidak berubah.

Catatan: source test bukan bukti pengujian kamera perangkat nyata. Catat tipe iPhone/iOS, browser, dan hasil setiap langkah ketika uji fisik dilakukan.
